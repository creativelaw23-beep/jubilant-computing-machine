### 🔨 Для создания standalone версии (Вариант 2 - Портативный)

#### **build_executable.bat** (1.9 KB) - для Windows
- Скрипт для создания standalone .exe файла
- **Требует:** Python 3.7+ и PyInstaller на компьютере разработчика
- **Использование:**
  ```bash
  build_executable.bat
  ```
- После выполнения будет создан файл `dist\Constitution_Quiz.exe`
- Скопируйте этот .exe файл на флэшку
- На целевом компьютере просто запустите .exe - никакого Python не требуется!

**Скачать:** [build_executable.bat](build_executable.bat)

#### **build_executable.sh** (2.0 KB) - для Linux/Mac
- Скрипт для создания standalone executable файла
- **Требует:** Python 3.7+ и PyInstaller на компьютере разработчика
- **Использование:**
  ```bash
  bash build_executable.sh
  ```
- После выполнения будет создан файл `dist/constitution_quiz`
- Скопируйте этот файл на флэшку
- На целевом компьютере просто запустите файл - никакого Python не требуется!

**Скачать:** [build_executable.sh](build_executable.sh)
