ВАРИАНТ 1️⃣: ПРОСТОЙ СПОСОБ (Требует Python)
═════════════════════════════════════════════════════════════════════════════

ШАГ 1: СКАЧАЙТЕ И РАСПАКУЙТЕ
──────────────────────────────
1. Скачайте файл: Constitution_Quiz_USB_v1.zip (27 KB)
2. Распакуйте архив на флэшку или компьютер
3. Вы получите папку со следующими файлами:
   • main.py
   • run_quiz.bat (для Windows)
   • run_quiz.sh (для Linux/Mac)
   • src/ (папка с кодом приложения)
   • README.md (документация)

ШАГ 2: НА ЦЕЛЕВОМ КОМПЬЮТЕРЕ
──────────────────────────────

WINDOWS:
───────
1. Вставьте флэшку в USB порт
2. Откройте папку с приложением
3. Двойной клик на файл "run_quiz.bat"
4. Если спросит про Python - нужно установить Python 3.7+
   Скачайте с: https://www.python.org/downloads/
5. После установки Python снова нажмите run_quiz.bat
6. Викторина запустится! 🎉

LINUX / MAC:
───────────
1. Вставьте флэшку в USB порт
2. Откройте терминал в папке с приложением
3. Выполните команду: bash run_quiz.sh
4. Если ошибка про Python - установите Python 3:
   Ubuntu/Debian: sudo apt-get install python3
   macOS: brew install python3
5. Снова выполните: bash run_quiz.sh
6. Викторина запустится! 🎉

ВАРИАНТ 2️⃣: ПОРТАТИВНЫЙ (Не требует Python)
═════════════════════════════════════════════════════════════════════════════

Если хотите что бы приложение работало БЕЗ Python:

ШАГ 1: НА ВАШЕМ КОМПЬЮТЕРЕ (с Python)
──────────────────────────────────────
Windows:
  1. Откройте командную строку в папке проекта
  2. Выполните: build_executable.bat
  3. Дождитесь завершения
  4. В папке dist/ появится файл Constitution_Quiz.exe

Linux/Mac:
  1. Откройте терминал в папке проекта
  2. Выполните: bash build_executable.sh
  3. Дождитесь завершения
  4. В папке dist/ появится файл constitution_quiz

ШАГ 2: НА ФЛЭШКУ
────────────────
1. Скопируйте файл Constitution_Quiz.exe (Windows)
   или constitution_quiz (Linux/Mac) на флэшку

ШАГ 3: НА ЦЕЛЕВОМ КОМПЬЮТЕРЕ
──────────────────────────────
Windows:
  - Просто двойной клик на Constitution_Quiz.exe
  - Викторина запустится сразу!

Linux/Mac:
  1. Откройте терминал в папке где находится файл
  2. Выполните: chmod +x constitution_quiz
  3. Выполните: ./constitution_quiz
  4. Викторина запустится!

ПРОВЕРКА PYTHON (для Варианта 1)
═════════════════════════════════

Windows:
  1. Откройте командную строку (Win+R, введите cmd, Enter)
  2. Выполните: python --version
  3. Должно вывести версию Python (например: Python 3.9.0)

Linux/Mac:
  1. Откройте терминал
  2. Выполните: python3 --version
  3. Должно вывести версию Python (например: Python 3.9.0)

ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ
═════════════════════════

Q: Получаю ошибку "Python не найден"
A: Установите Python 3.7+ с https://www.python.org/downloads/
   При установке ОБЯЗАТЕЛЬНО отметьте "Add Python to PATH"

Q: Нужно ли устанавливать дополнительные модули?
A: НЕТ! Приложение использует только встроенные модули Python

Q: На flэшке занимает слишком много места?
A: Вариант 1 займет ~1 MB, Вариант 2 ~100 MB
   Выберите подходящий для вас

Q: Можно ли запустить с разных флэшек?
A: Да! Приложение работает с любого носителя

Q: Что если на компьютере Windows 7?
A: Приложение работает на Windows 7, 8, 10, 11
   Python нужен версии 3.7 или выше
