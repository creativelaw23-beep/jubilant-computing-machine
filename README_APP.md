# Bitcoin Price Telegram Alert Application

Приложение для мониторинга цены Bitcoin и отправки уведомлений в Telegram 4 раза в день.

## 📋 Описание

Это приложение отслеживает текущую цену Bitcoin и автоматически отправляет уведомления в Telegram в установленное время с информацией о:
- Текущей цене Bitcoin
- Изменении цены за последние 24 часа
- Максимальной и минимальной цене за 24 часа
- Рыночной капитализации

## ⚙️ Требования

- Python 3.8+
- Pip (менеджер пакетов Python)
- Telegram Bot Token (от @BotFather)
- Telegram Chat ID

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка конфигурации

Скопируйте `.env.example` в `.env` и заполните необходимые значения:

```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_CHAT_ID=ваш_chat_id
NOTIFICATION_TIMES=06:00,12:00,18:00,23:00
TIMEZONE=Europe/Moscow
```

### 3. Запуск приложения

```bash
python app.py
```

## 📝 Переменные окружения

### Обязательные
- **TELEGRAM_BOT_TOKEN** - Токен вашего Telegram бота (от @BotFather)
- **TELEGRAM_CHAT_ID** - ID вашего чата или пользователя

### Опциональные
- **NOTIFICATION_TIMES** - Время отправки уведомлений (по умолчанию: `06:00,12:00,18:00,23:00`)
- **TIMEZONE** - Часовой пояс (по умолчанию: `UTC`). Примеры: `Europe/Moscow`, `Europe/London`, `America/New_York`
- **BITCOIN_VS_CURRENCY** - Валюта для цены (по умолчанию: `usd`)
- **LOG_LEVEL** - Уровень логирования (по умолчанию: `INFO`)

## 🤖 Как получить Telegram Bot Token

1. Откройте Telegram и найдите бота @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания нового бота
4. Скопируйте полученный токен в переменную `TELEGRAM_BOT_TOKEN`

## 📱 Как получить свой Chat ID

### Способ 1: Через бот
1. Отправьте любое сообщение боту, которого вы создали
2. Перейдите по ссылке: `https://api.telegram.org/bot{TELEGRAM_BOT_TOKEN}/getUpdates`
3. Найдите ваш Chat ID в поле `message.chat.id`

### Способ 2: Через @userinfobot
1. Найдите бота @userinfobot
2. Отправьте ему /start
3. Ваш Chat ID будет показан сразу

## 🐛 Решение проблем

### "Failed to connect to Telegram"
- Проверьте, что `TELEGRAM_BOT_TOKEN` верный
- Убедитесь, что у вас есть интернет соединение
- Проверьте, что бот работает (@BotFather → /mybots → выберите бота → Bot Settings)

### "TELEGRAM_CHAT_ID is required"
- Убедитесь, что вы скопировали и сохранили `.env` файл
- Проверьте, что `TELEGRAM_CHAT_ID` установлен и верный

### Уведомления не приходят вовремя
- Проверьте, что `NOTIFICATION_TIMES` в правильном формате (HH:MM)
- Проверьте, что установлен правильный `TIMEZONE`
- Убедитесь, что приложение запущено и работает

### API Error (429)
- CoinGecko имеет ограничение на количество запросов
- Приложение должно работать нормально, так как отправляет запросы только 4 раза в день

## 🔄 Как это работает

1. **Инициализация** - Приложение загружает конфигурацию и подключается к Telegram
2. **Планирование** - Создается расписание для отправки уведомлений в указанное время
3. **Мониторинг** - Приложение проверяет расписание каждую минуту
4. **Отправка** - Когда наступает время, приложение:
   - Получает текущую цену Bitcoin с CoinGecko API
   - Форматирует сообщение с информацией о цене
   - Отправляет сообщение в Telegram
