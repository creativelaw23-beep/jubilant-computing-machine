# Распределение приложения на USB флэшку

## Вариант 1: Быстрый способ (требует Python)

### Windows
1. Скопируйте всю папку проекта на USB флэшку
2. На целевом компьютере двойной клик на `run_quiz.bat`
3. Приложение запустится

**Требования:** Python 3.7+ установлен на компьютере

### Linux/Mac
1. Скопируйте всю папку проекта на USB флэшку
2. На целевом компьютере откройте терминал в папке проекта
3. Выполните команду:
   ```bash
   bash run_quiz.sh
   ```
4. Приложение запустится

**Требования:** Python 3.7+ установлен на компьютере

---

## Вариант 2: Портативный способ (самостоятельный исполняемый файл)

### Для Windows

**Шаг 1: Подготовка на компьютере разработчика**

1. Убедитесь, что установлены:
   - Python 3.7 или выше
   - PyInstaller (установите: `pip install pyinstaller`)

2. В корне папки проекта выполните:
   ```bash
   build_executable.bat
   ```

3. Дождитесь завершения. Исполняемый файл будет создан в папке `dist/Constitution_Quiz.exe`

**Шаг 2: Копирование на флэшку**

1. Скопируйте файл `dist/Constitution_Quiz.exe` на USB флэшку
2. Создайте текстовый файл `README.txt` на флэшке со следующим содержимым:
   ```
   КОНСТИТУЦИОННАЯ ВИКТОРИНА

   Для запуска:
   Просто двойной клик на Constitution_Quiz.exe

   Больше ничего не требуется!
   ```

**Шаг 3: Использование**

- На любом компьютере с Windows просто двойной клик на `Constitution_Quiz.exe`
- Приложение запустится сразу, Python не нужен

### Для Linux/Mac

**Шаг 1: Подготовка на компьютере разработчика**

1. Убедитесь, что установлены:
   - Python 3.7 или выше
   - PyInstaller (установите: `pip3 install pyinstaller`)

2. В корне папки проекта выполните:
   ```bash
   bash build_executable.sh
   ```

3. Дождитесь завершения. Исполняемый файл будет создан в папке `dist/constitution_quiz`

**Шаг 2: Копирование на флэшку**

1. Скопируйте файл `dist/constitution_quiz` на USB флэшку
2. Создайте текстовый файл `README.txt` на флэшке со следующим содержимым:
   ```
   КОНСТИТУЦИОННАЯ ВИКТОРИНА

   Для запуска на Linux/Mac:
   1. Откройте терминал в папке флэшки
   2. Выполните: chmod +x constitution_quiz
   3. Выполните: ./constitution_quiz
   ```

**Шаг 3: Использование**

- На компьютере с Linux/Mac откройте терминал в папке флэшки
- Выполните: `./constitution_quiz`
- Приложение запустится, Python не нужен

## Сравнение вариантов

| Характеристика | Вариант 1 | Вариант 2 |
|---|---|---|
| **Требует Python** | Да | Нет |
| **Размер на флэшке** | ~500 KB | ~50-100 MB |
| **Скорость запуска** | Медленнее | Быстрее |
| **Кроссплатформенность** | Да | Требует разных файлов |
| **Сложность подготовки** | Простая | Средняя |
| **Идеально для** | Техники, где есть Python | Обычные компьютеры |

## Автоматизированный скрипт для подготовки флэшки

### Windows: build_and_copy_to_usb.bat

```batch
@echo off
REM Создание исполняемого файла и копирование на флэшку

REM Создаем исполняемый файл
call build_executable.bat

REM Запрашиваем букву диска флэшки
set /p DRIVE="Enter USB drive letter (e.g., D): "

REM Копируем файл
copy "dist\Constitution_Quiz.exe" "%DRIVE%:\"
copy USB_DISTRIBUTION.md "%DRIVE%:\"

echo.
echo Files copied to USB drive %DRIVE%:
pause
```

## Часто задаваемые вопросы

### Q: Windows защитник выдает предупреждение при запуске exe
A: Это нормально. Нажмите "More info" → "Run anyway". Это происходит потому что файл новый.

### Q: На флэшке появляются лишние папки как __pycache__
A: Это нормально. Это временные файлы Python. Вы можете их удалить перед использованием флэшки.

### Q: Как проверить что приложение работает на другом компьютере?
A:
- Для Варианта 1: убедитесь что Python установлен
- Для Варианта 2: просто запустите исполняемый файл - больше ничего не нужно

### Q: Можно ли использовать Вариант 2 на Mac?
A: Да, если вы создадите исполняемый файл на компьютере с Mac используя `build_executable.sh`

### Q: Почему исполняемый файл такой большой?
A: Потому что он содержит весь Python и все необходимые библиотеки. Это нормально для PyInstaller.

## Дополнительные возможности

### Добавление иконки для исполняемого файла

1. Положите файл `icon.ico` (или `icon.png`) в корень проекта
2. Отредактируйте `build_executable.bat`:
   ```batch
   python -m PyInstaller --onefile --windowed --icon=icon.ico ...
   ```
3. Пересоздайте исполняемый файл

### Коммерческое распределение

Если вы планируете распределять приложение широко:
1. Рассмотрите подписание исполняемого файла (подпись кода)
2. Используйте инсталлятор вместо простого exe (NSIS, Inno Setup)
3. Добавьте лицензионное соглашение
4. Протестируйте на разных версиях Windows/macOS
